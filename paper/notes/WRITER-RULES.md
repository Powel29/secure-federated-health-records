# Shared rules for section writers (Stage 3) and fixers (Stage 6)

Read `.claude/skills/ieee-paper/SKILL.md` first. Its rules are binding. This
file adds what Stage 1–2 found, which overrides any doc it contradicts.

## Mechanics

- Source tags: every technical sentence ends with a LaTeX comment on the same
  line or the line after: `% src: facts-F2#14` (several: `% src: facts-F2#14, facts-F3#7`).
  Fact sheets: `paper/notes/facts-F1.md` … `facts-F8.md`, `facts-live.md`.
  If no fact supports a sentence, the sentence does not go in. Do not invent
  facts and do not cite sources outside the fact sheets. If you need a fact
  that is missing, you may read the cited source file yourself, but then add
  the fact to the end of the fact sheet as a new numbered entry
  (`N. <statement> — <path:line> (added by Wn)`) and tag it.
- Citations: only keys that exist (not DROPPED) in
  `paper/notes/refs-verified.bib`. W1 copies all of them into `paper/refs.bib`;
  the orchestrator prunes uncited ones later. Missing reference →
  `\cite{TODO-topic}` (a verifier treats any surviving TODO- key as a BLOCKER).
- Figures: TikZ / pgfplots only. No `\includegraphics`. Plot data from
  `paper/data/*.csv` via `\addplot table`, or coordinates generated by a script.
  Single-column figures must fit `\columnwidth` (≈ 3.5 in) and stay legible
  (`\footnotesize` minimum for labels). Use `figure*` only if truly needed.
- Tables go in `paper/tables/<name>.tex` and are `\input` from your section.
  Generate them from CSV/fact/raw-run data with a small script saved next to
  the data (`paper/data/make_<name>.py`, run with `.venv/Scripts/python.exe`),
  never retyped numbers. Use `booktabs`, `\footnotesize`, fit `\columnwidth`.
- Preamble is fixed in `paper/main.tex` (IEEEtran conference, fontspec Times,
  amsmath, newtxmath, booktabs, array, url, tikz with arrows.meta, positioning,
  automata, shapes.geometric, calc, fit, backgrounds; pgfplots 1.18; hyperref).
  Do not edit main.tex. If you need another package or TikZ library, say so in
  your report instead.
- Labels (use exactly these so cross-references resolve):
  sections `sec:intro sec:related sec:threat sec:overview sec:lifecycle
  sec:breakglass sec:security sec:traffic sec:eval sec:limits sec:conclusion`;
  `tab:related` (W1), `fig:components` (W2), `fig:states tab:transitions` (W3),
  `fig:sequence fig:gate fig:chain` (W4; you may merge gate+chain into one
  figure but keep both labels resolvable, or drop one and say so),
  `tab:claims tab:secprops tab:wire` (W5), `tab:bench fig:latency
  fig:expansion` (W6). Prefix any extra label with your section name.
- Compile check: do NOT write `paper/build/main.*` (the orchestrator owns the
  full build). To check your own file, create `paper/build/<you>/test.tex`
  with the exact preamble of `paper/main.tex` and
  `\input{D:/Powel/MIT/Projects/secure-federated-health-records/paper/sections/<file>}`,
  then `mkdir -p paper/build/<you> && /c/Users/user/AppData/Local/Programs/tectonic/tectonic.exe -X compile paper/build/<you>/test.tex --outdir paper/build/<you> --keep-logs`
  (citations will show as undefined there; that is fine). Or check one
  figure with the `compile_latex` tool (load it via ToolSearch
  `select:mcp__103fd11a-b91a-4fc2-bd57-9f41c8a996b4__compile_latex`) wrapped in a
  small `article`. Never send the whole paper to compile_latex.
- Do not change git state, do not edit anything outside your own section/table/
  data files (plus appending facts as above), do not download or install anything.

## Facts that override the docs (code wins)

- **Grant.** The code has no Grant transition and no key wrapping on consent
  (`src/consent/service.py:7`: consent does not wrap or re-wrap records;
  facts-F1). The skill and PROJECT.md §4 item 1 say "Grant adds a key
  wrapping": do NOT repeat that. Describe GRANTED as the baseline state.
  Rotation happens only on Revoke and at expiry (new DEK, policy root,
  emergency key + 3-of-4 shares, search index). Break-glass open rotates
  nothing. Never write "every transition rotates" or "every transition is a
  key-rotation event" (PROJECT.md §1 still says that; it is stale).
- States: `GRANTED, REVOKED, EMERGENCY_OPEN, EXPIRED`; 7 legal pairs
  (facts-F1). REVOKED→GRANTED is legal but nothing in the code produces it —
  say so if you show it. EXPIRED→REVOKED comes from ADR-0058 (Proposed).
- Split: weighted 3-of-4 over GF(p), p = 2^256+297 (a **257-bit** prime; docs
  that say 256-bit are wrong). Custodian x=1, home authority x=2, audit service
  x=3 and x=4. The gate only checks for 3 distinct x values; that every
  qualifying set contains an audit share follows from the distribution, not a
  gate check (facts-F2). Any doc saying 2-of-3, 2-of-2 or "share 3" alone is
  stale, including ADR-0019/0043/0044/0057/0065/0067/0069/0079,
  ARCHITECTURE §5, docs/federation-topology.md and PROJECT.md §5 item 13's
  "share 3".
- ElGamal/PRE/KEM/share sealing use a **256-bit demonstration group**
  (ADR-0079, Proposed), not production strength. PRE `rk = sk_a·sk_b^-1` is
  bidirectional, needs both secret keys, has no proof, and nothing outside
  `pre/` calls `reencrypt`; break-glass delivers the DEK by a KEM to the
  clinician's ElGamal key (facts-F3). ADRs 0001/0012/0018 still say
  "unidirectional": wrong.
- AES-256-GCM, 12-byte nonce, 16-byte tag; HKDF-SHA256; ECDSA P-256/SHA-256;
  `secrets` RNG. Record payload is encrypted with **no AAD** in the shipped
  ingest path; only the DEK wrapping binds record, policy and generation.
  RSA-OAEP is in the docs but not implemented. Policy tree: AND/OR/LEAF only.
- Assertion: lifetime ≤ 15 min, ≤ 30 s future skew; emergency window 4 h in
  deployment (facts-F2). Commit at `src/audit/share_custody.py:94-110` before
  shares are sealed and returned (`src/api/audit_service.py:425-446`).
- The facility's truncation check compares sequence numbers only; it does not
  verify entry signatures. A restarted audit service gets a new signing key
  (from code reading, not observed in a run).
- System: 2 facilities, 2 authorities, audit, custodian, Postgres, one Django
  portal, all on one machine (simulated federation). Docs saying "five
  services" are wrong. Federation services connect to Postgres as the
  `postgres` superuser; only the portal is role-restricted. HTTP TLS uses
  self-signed, server-only certs with no version/cipher pinned.
- Proposed (not ratified) ADRs — write "this build chooses…", never "the team
  agreed": 0045, 0047, 0053, 0054, 0058, 0064, 0066, 0067, 0070, 0071, 0072,
  0073, 0079, 0084, 0085, 0089 (check the Status recorded in the fact sheets
  for any other ADR).
- Wire (facts-F6): p55 run 2026-10-21 @99092d1 (nothing in wire/src/deploy/
  tests/wire changed since): preconditions and claims 1–4 pass. Claim 1 holds
  under TLS only; the plain capture is the positive control. COMMIT reaches the
  wire 1.35 ms before the `/breakglass/release` response. Multi-search leakage
  numbers come from the p53 runs of **2026-10-19, which predate the 3-of-4
  change** — always label them with that date. ADR-0079's 2.27 ms figure is
  pre-3-of-4: do not quote it.
- Live run (facts-live): 2026-10-21 @57a1a8c: C1–C11 all **holds** (35/35
  system tests); pytest 1006 passed, 2 skipped (dumpcap-missing tests that skip
  by design), 0 failed. Quote claim wording as the live table prints it.
- Benchmarks (facts-F7): working tree = HEAD 57a1a8c, n=30, warm-up 5, ms.
  environment.json records no commit and no library versions. "local-processes"
  is in fact six uvicorn servers run as threads inside the benchmark process.
  HTTP figures include a second signed hop to the audit service and a Postgres
  write and are unstable across runs on the same machine. Ciphertext expansion
  is a constant 16 B (GCM tag) and excludes nonce, wrappings, shares and index.
- Related work (facts-F8): arXiv 2511.17464 **has** a break-glass mechanism
  (two-physician co-signed emergency grant, 2 h, logged on-chain; key release
  via an unimplemented HSM guardian, not log-gated; revocation flips an
  on-chain flag) — say so fairly. Do not use the name "PORTEX"; cite
  `li2025accountable` under its real title. Kroll et al. is an undated
  manuscript — never print "2018" for it.
- Review findings marked out of date (2-of-3 bypass, unchecked assertion,
  expiry shares, "5/11 claims") must never appear as current.
